최근 판별 기록

Vercel 배포 연결 구조

이 서비스는 보안을 위해 API 키를 프론트엔드에 노출하지 않고 Vercel Serverless Function을 거쳐 호출하도록 설계되었습니다.

[요청 흐름]
1. 브라우저 (index.html) ➔ 이미지 전달
2. POST /api/generate (Vercel Serverless)
3. process.env.GEMINI_API_KEY 로 Gemini API 호출
4. 브라우저로 분석 결과 JSON 반환

💡 Vercel 대시보드의 [Settings] ➔ [Environment Variables]에서 GEMINI_API_KEY를 등록하고 배포하시면 바로 서버리스 함수가 작동합니다.

환경 설정

이 앱은 Vercel 환경 변수(GEMINI_API_KEY) 기반의 /api/generate 서버리스 함수로 안전하게 동작합니다.

✅ 안전한 배포 상태 안내

클라이언트 코드에는 어떠한 API 키도 저장되지 않습니다. Vercel 대시보드에서 키를 설정하세요.
